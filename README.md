> **题目**：基于大语言模型的游戏知识问答与辅助方法设计与实现
> **研究方向**：大语言模型、检索增强生成（RAG）、垂直领域知识问答
> 
> **最低完成要求**：
> 1. 构建一个包含300-800条游戏知识的结构化知识库。
> 2. 构建包含不少于100条问题的测试集（含标注）。
> 3. 实现RAG完整链路（切分、向量化、检索、生成）。
> 4. 完成“无RAG vs RAG”主对比实验，以及“两种切分粒度”的对比实验。
> 5. 完成评测脚本与错误案例分析。
> 
> **拓展目标**：优化检索策略（如混合检索），或加入多轮对话能力。
> 
> **当前进展**：已明确课题，完成参考文献筛选，正在构建知识库和测试集。
> **下一步计划**：跑通云端API Baseline，搭建本地RAG系统。
> *注：本课题涉及的游戏知识库数据来源于崩坏星穹铁道官方开放Wiki，数据由本人手工整理标注，仅用于学术研究，不涉及商业用途。*
