# 系统架构设计

## 总体流程
用户问题 -> [检索器(向量/BM25/混合)] -> 知识库文档 -> 组装提示词 -> [LLM生成(DeepSeek)] -> 答案

```
用户问题
   │
   ▼
┌──────────────┐   检索(命中 top-k 片段)     ┌──────────────────┐
│  Retriever   │ ─────────────────────────▶│ 知识库(角色数据csv)│
│ vector/BM25  │                            └──────────────────┘
└──────────────┘
   │  检索片段
   ▼
┌──────────────┐   组装 prompt_template     ┌──────────────────┐
│  Prompt组装  │ ─────────────────────────▶│  Generator(LLM)  │
└──────────────┘                           │  deepseek-flash  │
                                           └──────────────────┘
                                                     │
                                                     ▼
                                                  答案输出
```

## 模块划分（src/rag/）
- documents.py：CSV 加载与分块
- embed.py：BGE 中文嵌入
- retriever.py：向量/BM25/混合检索
- generator.py：DeepSeek LLM 生成
- rag.py：RAG 主管线

## 评测（evaluation/）
- 在冻结测试集上计算：答案正确率、拒答率、知识命中率、引用准确性。
