# experiments/

实验目录。每次实验的产出（目的、配置、命令、结果表、结论、问题）保存在对应子目录的 Markdown 文档中。

- `baseline/`：无 RAG 基线（直接 LLM 问答），含 `baseline_no_rag.py`、`config.yaml`、`command.txt`、`notes.md`、`metrics.csv`。
- `exp01-retrieval-method/`：**EXP-001 检索方法主实验**。比较无 RAG / BM25 / 向量 / 混合 RRF，row / field / entity-grouped 三种切块，top-k=3/5/10。主结果表见 `EXP-001-retrieval-method.md`。
- `exp02/`：**EXP-002 实体约束检索（实体消歧）**。验证针对"黑塔/大黑塔"等易混淆实体的实体约束检索是否有效，并汇总本轮 9 配置矩阵结论。见 `EXP-002-entity-constraint.md`。

## 主结果速览（120 题冻结测试集）

| 配置 | 可回答(45) | 不能回答(40) | 易混淆(35) | 总体(120) |
|---|---|---|---|---|
| 无 RAG | 0.400 | 0.050 | 0.686 | 0.367 |
| BM25·field·k5 | 0.800 | 0.925 | 0.600 | 0.783 |
| 向量·field·k5 | 0.778 | 1.000 | 0.771 | 0.850 |
| 混合 RRF·field·k5 | 0.911 | 0.950 | 0.943 | 0.933 |
| 向量·row·k5 | 0.422 | 0.975 | 0.314 | 0.575 |
| 向量·entity·k5 | 0.956 | 0.950 | 0.971 | 0.958 |
| 向量·field·k3 | 0.711 | 0.975 | 0.714 | 0.800 |
| 向量·field·k10 | 0.800 | 1.000 | 0.857 | 0.883 |
| 向量·field·k5·实体约束 | 0.778 | 0.975 | 0.771 | 0.842 |

结论：知识组织方式影响最大（entity-grouped 最优）；混合 RRF 优于单路；k5 为准确率与引用精度的平衡点；**实体消歧未带来易混淆增益（瓶颈在字段级生成，非检索到错误实体）**。
